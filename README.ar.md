Tunefy هو عميل موسيقى غني بالميزات ويركز على الخصوصية وتم تصميمه باستخدام Flutter. يتدفق من
**أكثر من 15 مصدرًا مفتوحًا وبدون مفتاح** مع سلسلة احتياطية تلقائية، أي مسار يفشل في أحدها
يلعب مزود في اليوم التالي. فهو يوفر تجربة متميزة خالية من الإعلانات مع تشغيل الخلفية،
التنزيلات دون اتصال بالإنترنت، وكلمات الأغاني المتزامنة **والمترجمة**، و**AI DJ**، وراديو الإنترنت، والحفلات الموسيقية،
قوائم التشغيل المشتركة Blend وواجهة المستخدم الحديثة Liquid Glass والتخزين المؤقت الذكي للخلفية - مع أو بدونه
حساب.

> [!NOTE]
> يتم توزيع Tunefy مباشرة من هذا المستودع (إصدارات APK). إنه** غير** متاح
> على Google Play Store.

## 🚀 الميزات الرئيسية

### 🎨 Liquid Glass واجهة المستخدم/تجربة المستخدم
- ** سمات Glassmorphic الديناميكية** - تصميم متميز في الوضعين الداكن والفاتح عبر `liquid_glass_easy`. يستخدم وضع الإضاءة لونًا أبيض شبه شفاف يتكيف مع صورة الألبوم.
- **تظليل وطمس مخصص** — ألواح وتراكبات زجاجية بلوري عالية الأداء تتكيف مع ألوان العمل الفني.
- **عناصر مدركة للتباين** — يتم قلب أيقونات شريط الحالة وعناصر التحكم وشرائح التمرير والقوائم تلقائيًا من أجل الوضوح.
- **تحسين الشاشة الكبيرة وسطح المكتب** — تخطيطات المشغل سريعة الاستجابة (حتى 1300 بكسل)، ومربعات الحوار المركزية، وشريط بحث علوي مخصص لسطح المكتب/الكمبيوتر اللوحي.

### 🎧 صوت غامر، كلمات وكاريوكي
- **Word-by-Word Karaoke** — تمتلئ الكلمات بالألوان في الوقت الفعلي بينما يغني الفنان (+60 إطارًا في الثانية).
- **المسح المتزامن سطرًا تلو الآخر** — تأثير المسح التدريجي مع تمييز الخط النشط والتمرير السلس.
- **كلمات مترجمة** — تتم ترجمة كلمات الأغاني آليًا (DeepL) إلى لغة تطبيقك بسرعة.
- **وضع Lofi** — حوّل أي مسار إلى أجواء Lofi: إبطاء بمقدار 0.9×، تصحيح طبقة الصوت، الصدى الأصلي.
- **المعادل والمؤثرات الأصلية** — معادل صوت على مستوى النظام مع تشغيل الخلفية وصوت خارج الشاشة.
- ** التحكم في الصوت والجودة متعدد اللغات** - اكتشف اللغات الصوتية المتاحة وقم بتشغيل البث بجودة عالية/متوسطة/منخفضة.

### 🤖 AI DJ والتخصيص
- **AI DJ Assistant (Gemini)** — DJ محادثة يقرأ ذوقك، وينشئ قوائم تشغيل ذكية، ويستقبل الطلبات.
- **إشارات الذوق** — يتعرف تسجيل الذوق لكل مسار على ما تحبه ويؤدي إلى التوصيات.
- **Wrapped وإحصائيات الاستماع** — مراجعتك السنوية: أفضل الفنانين، والحالات المزاجية، وكبسولات الاستماع.
- **نظام التخزين المؤقت الذكي** — تخزين مؤقت غير متزامن للصوت + عمل فني متعدد الدقة للتشغيل الفوري دون انتظار.

### 🌍 الاكتشاف عبر أكثر من 15 مصدرًا
Tunefy يحل التشغيل من خلال **سلسلة احتياطية تلقائية** عبر هؤلاء الموفرين (بدون مفتاح = لا حاجة إلى مفتاح واجهة برمجة التطبيقات):

| المصدر | اكتب | ملاحظات |
|---|---|---|
| **YouTube / موسيقى يوتيوب** | فيديو / صوت | الأساسي عبر youtube_explode + واجهة برمجة التطبيقات الداخلية |
| **Jamendo** | بدون مفتاح | كتالوج المشاع الإبداعي |
| **Deezer** | بدون مفتاح | الكتالوج + البيانات الوصفية |
| **Audius** | بدون مفتاح | فنانين لامركزيين |
| **جيو سافن** | فتح API | البيانات الوصفية السريعة والبحث |
| **Invidious** | بدون مفتاح | YouTube مرآة (4 مرات) |
| **Piped** | فتح API | YouTube مرآة |
| **OpenVerse** | بدون مفتاح | CC الصور/الصوت *(جديد)* |
| **Wikimedia Commons** | بدون مفتاح | الوسائط المفتوحة *(جديد)* |
| **Beatport** | بدون مفتاح | الكترونيك/رقص *(جديد)* |
| **Dailymotion** | بدون مفتاح | فيديو احتياطي *(جديد)* |
| **ccMixter** | بدون مفتاح | ثقافة الريمكس *(جديد)* |
| **Internet Archive** | بدون مفتاح | صوتيات تاريخية *(جديد)* |
| **Radio Browser** | بدون مفتاح | محطات راديو الانترنت |
| **iTunes / MusicBrainz / Last.fm** | فتح | البيانات الوصفية والرسوم البيانية والأنواع |

- **Cloud Stream Relay** — يقوم مرحل مستضاف ذاتيًا بحل و**تفويض وحدات البايت الصوتية** من عنوان IP نفسه الذي يستخدمه المشغل، مع تجنب HTTP 403 الذي ترجعه روابط Googlevideo المقفلة IP. انظر [Servers](#-خوادم-الواجهة-الخلفية-والبث-المباشر).
- **Spotify استيراد** — الصق أي عنوان URL لقائمة تشغيل Spotify عامة (أو قم بمسح رمز Spotify) لاستيراد المقاطع الصوتية.
- **البحث العالمي** — بحث واحد عبر الأغاني ومقاطع الفيديو والألبومات والفنانين والبودكاست.
- **مشاركة للتشغيل** — مشاركة روابط موسيقى YouTube/YT مباشرة في Tunefy.

### 📻 الراديو والحفلات والفيديو
- **راديو الإنترنت** — آلاف المحطات الحية (Radio Browser).
- **الحفلات الموسيقية** — اكتشف الأحداث المباشرة القريبة منك من خلال صفحات غنية بالتفاصيل.
- **خلاصة المقاطع** — خلاصة فيديو قصيرة عمودية للمجتمع والمقاطع الشائعة.
- **مشغل الفيديو** — تشغيل الفيديو بالكامل بخلفيات فيديو قماشية.
- **DJ Mixes** — اكتشاف وتشغيل DJ/mix مخصص.

### 🤝 وسائل التواصل الاجتماعي والمزج والمجتمع
- **Blend قوائم التشغيل** — أنشئ قائمة تشغيل مشتركة برمز انضمام قصير (مثل `KORA-4821`)؛ يمكن لأي شخص لديه الكود الاستماع والمساهمة، مثل Spotify Blend الروابط.
- **خلاصة المجتمع** — ابحث عن المقاطع التي تم تحميلها بواسطة المجتمع وبثها واكتشفها.
- **متابعة الفنانين** — متابعة الفنانين/القنوات لتتبعهم.
- **قائمة الانتظار الذكية والتشغيل اللانهائي** — قائمة الانتظار التلقائية مع سلوك واضح وذكي.

### 🔐 الخصوصية والحسابات
- **لا يلزم وجود حساب** — يتم تخزين المفضلة وقوائم التشغيل والسجل محليًا بشكل افتراضي.
- **مجهول + تسجيل الدخول إلى Google** — تسجيل دخول اختياري (هوية الجهاز المجهول أو Google عبر Supabase Auth) للمزامنة السحابية والملف الشخصي.
- **التنزيلات دون اتصال** — تنزيل الأغاني ومقاطع الفيديو للاستماع إليها في وضع عدم الاتصال.
- **الربط العميق** — مخطط URL مخصص كامل لفتح/تشغيل الأغاني والفنانين والألبومات وقوائم التشغيل عبر المتصفح أو الروابط المشتركة.
- **خالية من الإعلانات وموثوقة** — الاستماع دون انقطاع مدعومًا بمرحلات مفتوحة (Last.fm، MusicBrainz، iTunes) لضمان التشغيل.

## 🏗️الهندسة المعمارية

```
tunefy-music/
├── lib/                     # Flutter app (Riverpod + Just Audio)
│   ├── l10n/                # 14-language localization
│   ├── providers/           # Riverpod state
│   ├── screens/             # UI screens
│   ├── services/            # Sources, streaming, AI DJ, sync
│   └── widgets/             # Reusable components
├── server/                  # ☁️ Cloud stream relay (Render)  ← see below
├── backend/                 # Local/stream API + yt-dlp helpers
├── supabase/migrations/     # Postgres schema + RLS policies
└── images/, assets/         # Screenshots & brand assets
```

** موثوقية التشغيل.** التطبيق لا يعتمد أبدًا على مزود واحد. إنه يستكشف المصادر في أ
سلسلة الأولوية (المرحل المحلي ← المرحل السحابي ← المرايا بدون مفتاح ← البيانات الوصفية/البحث عن العنوان)، مع أ
قاطع الدائرة الذي يتخطى المصدر الذي فشل. يقوم **التتابع السحابي** بحل الدفق وبعد ذلك
**يقوم بترحيل البايتات** من خلال اتصاله الخاص بحيث يتشارك الدقة والتشغيل في عنوان IP واحد — هذا هو الحال
ما الذي يتجنب IP-locked 403 على روابط Googlevideo.

## ⚙️ الإعداد والتثبيت

### المتطلبات الأساسية
- Flutter SDK (أحدث مستقر)
- Dart SDK
- Android Studio / رمز VS
- Java جدك 17

### التثبيت

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/grandelagbanou28-gif/tunefy-music.git
   cd tunefy-music
   ```

2. **تثبيت التبعيات:**
   ```bash
   flutter pub get
   ```

3. **قم بتشغيل التطبيق:**
   ```bash
   flutter run
   ```

4. **Build Release APK** (مقسمة بواسطة ABI لحجم أصغر):
   ```bash
   flutter build apk --split-per-abi
   ```

> تم خبز عنوان URL للترحيل السحابي في `lib/utils/api_constants.dart`
> (`relayBaseUrl`)، لذلك لا يلزم وجود علامة بناء. للإشارة إلى التتابع الخاص بك:
> `flutter run --dart-define=RELAY_BASE_URL=https://your-relay.onrender.com`.

## 🖥️ خوادم الواجهة الخلفية والبث المباشر

### ☁️ ترحيل التدفق السحابي — `server/` (تم نشره على Render)
يحل عنوان URL الصوتي YouTube **وينقل البايتات** بحيث يتشارك الهاتف والمحلل IP واحد
(رقم 403). FastAPI + yt-dlp، Docker، الطبقة المجانية.

| نقطة النهاية | الوصف |
| --- | --- |
| `GET /health` | مسبار الحياة (`ok`) |
| `GET /stream?videoId=X&key=K` | يتم الحل عبر yt-dlp → إرجاع عنوان URL `…/relay` (200 فقط إذا تم حله) |
| `GET /relay?videoId=X&key=K` | وكلاء البايتات الصوتية (النطاق المدرك → 206 للبحث) |

محمي بواسطة `RELAY_KEY` env var مشترك (إرجاع **401** بدونه). نشر: Render →
**Root Directory = `server`**, Docker, **Health Check = `/health`**. انظر `server/README.md`.

### 🎵 واجهة برمجة تطبيقات التطبيق — `backend/`
الواجهة الخلفية للبيانات/البحث (YouTube Music عبر youtubei.js + المصادر المفتوحة: Last.fm الأنواع،
MusicBrainz الإصدارات والعقود).

| نقطة النهاية | الوصف |
| --- | --- |
| `/api/search` | بحث الموسيقى / الفيديو |
| `/api/trending` | تتجه |
| `/api/charts` | مخططات موسيقى YT |
| `/api/playlist/:id` | تفاصيل قائمة التشغيل |
| `/api/moods`, `/api/moods/:id` | الفئات والحالات المزاجية (Last.fm احتياطي) |
| `/api/tags?tag=` | النوع الأعلى الأغاني / الألبومات (Last.fm) |
| `/api/newreleases` | الإصدارات الجديدة (MusicBrainz) |
| `/api/decades?year=` | الالبومات حسب العقد (MusicBrainz) |
| `/api/categories` | قائمة الفئات |

**محلي:** `cd backend && npm install && npm start` (المنفذ 8000).
**نشر (Vercel):** استيراد هذا الريبو، **Root Directory = `backend`**. انظر `backend/README.md`.

### 🗄️ قاعدة البيانات — `supabase/`
مخطط Postgres مع **الأمان على مستوى الصف**: يتم تحديد نطاق صفوف المستخدم إلى `auth.uid()`، الكتالوج هو
للقراءة فقط للمستخدمين المجهولين وقابل للكتابة فقط من خلال دور الخدمة. تشغيل عمليات الترحيل في Supabase
محرر SQL (بالترتيب).

[youtube_explode_dart](https://github.com/Hexer10/youtube_explode_dart) — العمود الفقري لـ Tunefy

يحافظ على Tunefy يعمل مع أحدث YouTube التغييرات.
