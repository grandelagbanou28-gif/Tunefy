Tunefy ẹ́ wà kliyán hudù tɔ tó kpótɔ́, ó ná sín àkókó (privacy) tɔ tú wà, ó kún nú Flutter ɖò.
Ó ɖò hudù ɖò lé **wɛ́ 15 ɖò kɛ́ hwé ɔ́nɔ́ wɛ́ klé (keyless)**, mɛ́ cascade tɔ tɔ ná ɔ̀n àgbà (fallback);
ayin tó kù lé ɔ́n ɔ́, ó kù tɔ́ ɔ́n ɔ̀n. Ó dé kliyán tón gbɔ, wɛ́ nìkún, wàtà àwa, ayin kún tɔ́ **àti ɖò tɔ**,
**DJ AI** tɔ, rádiò intɛrnè, kɔnsè, azá list tɔ kún bí, Liquid Glass UI tɔ ná àti cache tɔ tɔ —
bí ó yɔ akɔ́n ɔ́n, bí ó kù wɛ́.

> [!NOTE]
> Tunefy ɖò ɔ̀n mɛ̀ aká tɔ ná ɖò (APK release wè). Ó **wɛ́** nà lé
> Google Play Store lé.

## 🚀 Tɔ̀ɔ ná lé ɔ́n kún

### 🎨 Liquid Glass UI/UX
- **Tɛ́mɛ̀ Glassmorphic tɔ tɔ́** — Tɔ́ gbɔ ná lé Dark àti Light mode, lí `liquid_glass_easy`. Light Mode ɖò white à gbáyá tɔ ná, ó kún bí album art ná.
- **Shader tɔ kún àti mblur** — Pánél glasi tɔ ná ɔ̀n kpókpó, ó kún bí colɔ́rɔ́ artwork ná.
- **Tɔ ná ɔ́n kpɔ gbáyá** — Icôn bar ná, kɔ́ntrol, slider àti mènù wè ɔ̀n bɔ léyì ná tɔ́ tɔ kún bí ná.
- **Ékran lɔ́n àti Desktop** — Layout player tɔ tɔ (dé 1300px), dialog wè ná kún tɔ́, àti bar kpɔ ná lé desktop/tablet.

### 🎧 Hudù tɔ ɔ́n sín kú ɔ̀n, Ayin àti Karaoke
- **Karaoke word-by-word** — Ami wè gbáyá lé ayin tɔ ná, asinyɔ ná ɔ́n (60+ FPS).
- **Line-by-line sync** — Effect tɔ ná ɖò ɔ̀n ɔ́n, line tɔ ná kpókpó àti scroll tɔ gbɔ.
- **Ayin ɖò** — Ayin wè ɖò ná bí makin (DeepL) ɖò yɔ́ app ná lé, ó ɖò lé kálísì ná.
- **Lofi mode** — Ɖò ayin kpó ná bí Lofi: tɔ̀n 0.9×, pitch correction, reverb ná.
- **Equalizer àti effect tɔ tɔ** — EQ ná lé sístèm, playback ɔ̀n àti ékran kù.
- **Yɔ́ wè àti Kalité** — Detect yɔ́ audio wè, ó stream Kalité Dón/Títɛ̀/Kínkín.

### 🤖 AI DJ àti Personalization
- **AI DJ (Gemini)** — DJ tɔ kú yɔ̀ ɔ́n, ó kpɔ taste ná ɔ̀n, ó kún list gbɔ, ó bɔ request wè.
- **Taste signals** — Score ayin mɛ̀n ɔ́n, ó mǎ nú ò kún nǔ, ó dá recommendation ná.
- **Wrapped àti stats tɔ ná** — Sù ná ɖè: artist dón, mood wè, capsule wè.
- **Cache gbɔ** — Audio àti artwork (résolution wè) cache ɔ̀n ɔ́n, playback léa, ó ɔ̀n lɛ́.

### 🌍 Kpɔ ná lé Wɛ́ 15 ɖò ɔ́nɔ́

| Wɛ́ | Ná | Nù ɔ̀n |
|---|---|---|
| **YouTube / YT Music** | Video / Hudù | Tɔ tɔ, youtube_explode + API yí ɖò |
| **Jamendo** | Wɛ́ klé | Catalog Creative Commons |
| **Deezer** | Wɛ́ klé | Catalog + metadata |
| **Audius** | Wɛ́ klé | Artist wè ɔ́n wɛ́ tɔ̀tɔ́ |
| **JioSaavn** | API hwé | Metadata àti kpɔ ɖó |
| **Invidious** | Wɛ́ klé | YouTube yiyì (instance 4) |
| **Piped** | API hwé | YouTube yiyì |
| **OpenVerse** | Wɛ́ klé | Núɖò / hudù CC *(hɔ́n)* |
| **Wikimedia Commons** | Wɛ́ klé | Media hwé *(hɔ́n)* |
| **Beatport** | Wɛ́ klé | Electronic/dance *(hɔ́n)* |
| **Dailymotion** | Wɛ́ klé | Video fɛ́ àgbà *(hɔ́n)* |
| **ccMixter** | Wɛ́ klé | Remix *(hɔ́n)* |
| **Internet Archive** | Wɛ́ klé | Hudù sù tɔ̀nǔ *(hɔ́n)* |
| **Radio Browser** | Wɛ́ klé | Radio intɛrnè wè |
| **iTunes / MusicBrainz / Last.fm** | Hwé | Metadata, classement, genre wè |

- **Relay cloud tɔ** — Relay tɔ kún mɛ̀ ɔ́n, ó kpɔ stream ná, ó **relay byte hudù wè** lé IP kọ̀tɔ̀, IP ná player ná ɖò; ó avoid HTTP 403, tó Googlevideo link wè IP-locked ɖò. Kpɔ [Sɛ́va wè](#-backend--streaming-servers).
- **Fà ɔ̀n Spotify lé** — Paste Spotify link ɔ̀n ɔ́n hwé (ɔ́n scan Spotify code ná) fɛ́ fà ayin wè.
- **Kpɔ tɔ tɔ** — Search ɔ̀n fɛ́ song wè, video wè, album wè, artist wè àti podcast wè.
- **Share fɛ́ di** — Share YouTube/YT Music link wè ɖò Tunefy lé.

### 📻 Radyò, Kɔnsè àti Video
- **Radio intɛrnè** — Radio station dón (Radio Browser).
- **Kɔnsè** — Kpɔ kɔnsè wè tó lé ɔ̀n ɖésí, lí page detail gbɔ.
- **Clips Feed** — Clip video kúkú tɔ tɔ, vertical, community àti trending.
- **Video Player** — Video playback tɔ tɔ, background canvas.
- **DJ Mix** — DJ/mix kpɔ àti playback tɔ.

### 🤝 Sosyá, Blend wè àti Community
- **Blend List** — Kún list kún mɛ́ code kúkú (mɛ̀ `KORA-4821`); ɔ̀n kpó code ná, ó tɔ àti dá, bí Spotify Blend link wè.
- **Community Feed** — Search, stream àti kpɔ ayin community ná ɔ́n ɔ̀n.
- **Following Artist** — Follow artist/channel wè fɛ́ kpɔ ná wè.
- **Queue gbɔ àti Playback ɔ̀n kù kù** — Auto queue, clear tɔ gbɔ.

### 🔐 Àkókó (Privacy) àti Akɔ́n wè
- **Wɛ́ akɔ́n** — Favorite, list àti history yí ná lé local lé default.
- **Anonymous + Google Sign-In** — Sign-in fɛ́ (identity anonymous ɔ́n Google, Supabase Auth mɛ́) fɛ́ sync cloud àti profile.
- **Wàtà àwa** — Fà song àti video fɛ́ tɔ àwa.
- **Deep Linking** — URL scheme tɔ tɔ fɛ́ open/play song, artist, album àti list lé browser ɔ́n link kún ɖò.
- **Wɛ́ nìkún àti tɔtɔ** — Playback ɔ̀n wɛ́ brɛ̀n, mɛ́ relay hwé (Last.fm, MusicBrainz, iTunes) fɛ́ jìn playback ná.

## 🏗️ Sísísín ná

```
tunefy-music/
├── lib/                     # Flutter app (Riverpod + Just Audio)
│   ├── l10n/                # 14-language localization
│   ├── providers/           # Riverpod state
│   ├── screens/             # UI screens
│   ├── services/            # Sources, streaming, AI DJ, sync
│   └── widgets/             # Reusable components
├── server/                  # ☁️ Cloud stream relay (Render)  ← see below
├── backend/                 # Local/stream API + yt-dlp helpers
├── supabase/migrations/     # Postgres schema + RLS policies
└── images/, assets/         # Screenshots & brand assets
```

**Playback tɔtɔ.** App ná wɛ́ provider ɔ̀n. Ó probe wɛ́ lé priority cascade (relay local → relay cloud → mirror keyless → metadata/title search), mɛ́ circuit breaker tɔ, ó skip wɛ́ provider tó ná ɔ̀n error. **Relay cloud** ɖò stream ná, ó **relay byte wè** lé connection ɔ̀n ɔ́n, resolution àti playback kún IP kọ̀tɔ̀ — ná ɖò avoid Googlevideo link wè IP-locked 403 ná.

## 🖥️ Backend àti Streaming Servers

### ☁️ Cloud Stream Relay — `server/` (Render lé)
Ó kpɔ YouTube audio URL ná **àti relay byte wè**, téléphone àti resolver ná kún IP kọ̀tɔ̀ (wɛ́ 403). FastAPI + yt-dlp, Docker, tier hwé.

| Endpoint | Nù ɔ̀n |
| --- | --- |
| `GET /health` | Liveness probe (`ok`) |
| `GET /stream?videoId=X&key=K` | Ó kpɔ lé yt-dlp → ó dá URL `…/relay` (200 bí ó kpɔ ná) |
| `GET /relay?videoId=X&key=K` | Ó relay byte wè (Range-aware → 206 fɛ́ seek) |

Ó kɔ̀ `RELAY_KEY` env var mɛ́ (ó dá **401** bí ó kù). Deploy: Render →
**Root Directory = `server`**, Docker, **Health Check = `/health`**. Kpɔ `server/README.md`.

### 🎵 App API — `backend/`
Data/search backend ná (YouTube Music lé youtubei.js + sources hwé: Last.fm genre wè,
MusicBrainz release àti decades wè).

| Endpoint | Nù ɔ̀n |
| --- | --- |
| `/api/search` | Search music / video |
| `/api/trending` | Trending |
| `/api/charts` | YT Music charts |
| `/api/playlist/:id` | Playlist detail |
| `/api/moods`, `/api/moods/:id` | Category àti mood wè (Last.fm fallback) |
| `/api/tags?tag=` | Genre top tracks/albums (Last.fm) |
| `/api/newreleases` | Release wè hɔ́n (MusicBrainz) |
| `/api/decades?year=` | Album wè decade wè (MusicBrainz) |
| `/api/categories` | Category list |

**Local:** `cd backend && npm install && npm start` (port 8000).
**Deploy (Vercel):** import repository ná, **Root Directory = `backend`**. Kpɔ `backend/README.md`.

### 🗄️ Database — `supabase/`
Postgres schema mɛ́ **Row-Level Security**: user row wè ná `auth.uid()` kɔ̀, catalog ná read-only lé anonymous, service role ná ɔ̀n writable. Run migration wè lé Supabase SQL Editor (lé order).
