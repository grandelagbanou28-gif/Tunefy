Tunefy एक सुविधा-संपन्न, गोपनीयता-केंद्रित संगीत क्लाइंट है जिसे Flutter के साथ बनाया गया है। यह से प्रवाहित होता है
**15+ खुले और बिना चाबी वाले स्रोत** एक स्वचालित फ़ॉलबैक कैस्केड के साथ, इसलिए एक ट्रैक जो एक पर विफल रहता है
प्रदाता अगले पर खेलता है। यह बैकग्राउंड प्लेबैक के साथ एक प्रीमियम विज्ञापन-मुक्त अनुभव प्रदान करता है,
ऑफ़लाइन डाउनलोड, सिंक्रनाइज़ **और अनुवादित** गीत, एक **एआई डीजे**, इंटरनेट रेडियो, संगीत कार्यक्रम,
साझा Blend प्लेलिस्ट, एक आधुनिक Liquid Glass यूआई, और स्मार्ट पृष्ठभूमि कैशिंग - के साथ या उसके बिना
एक खाता.

> [!NOTE]
> Tunefy सीधे इस रिपॉजिटरी (एपीके रिलीज) से वितरित किया जाता है। यह **नहीं** उपलब्ध है
> Google Play Store पर.

## 🚀 प्रमुख विशेषताएँ

### 🎨 Liquid Glass यूआई/यूएक्स
- **डायनेमिक ग्लासमॉर्फिक थीम्स** - `liquid_glass_easy` के माध्यम से डार्क और लाइट मोड में प्रीमियम स्टाइल। लाइट मोड एक अर्ध-पारदर्शी सफेद रंग का उपयोग करता है जो एल्बम कला के अनुकूल होता है।
- **कस्टम शेडर्स और ब्लर** - उच्च प्रदर्शन वाले फ्रॉस्टेड ग्लास पैनल और ओवरले जो कलाकृति के रंगों के अनुकूल होते हैं।
- **कंट्रास्ट-अवेयर एलिमेंट्स** - सुपाठ्यता के लिए स्टेटस बार आइकन, नियंत्रण, स्लाइडर और मेनू ऑटो-इनवर्ट।
- **बड़ी स्क्रीन और डेस्कटॉप ऑप्टिमाइज़ेशन** - रिस्पॉन्सिव प्लेयर लेआउट (1300px तक), केंद्रित संवाद और डेस्कटॉप/टैबलेट के लिए एक समर्पित शीर्ष खोज बार।

### 🎧 इमर्सिव ऑडियो, गीत और कराओके
- **शब्द-दर-शब्द कराओके** - जैसे ही कलाकार गाता है (60+ एफपीएस) शब्द वास्तविक समय में रंग भर देते हैं।
- **लाइन-बाय-लाइन सिंक्ड स्वीप** - सक्रिय-लाइन हाइलाइट और स्मूथ स्क्रॉलिंग के साथ प्रगतिशील स्वीप प्रभाव।
- **अनुवादित गीत** - गीत तुरंत आपकी ऐप भाषा में मशीन-अनुवाद (DeepL) किए जाते हैं।
- **लोफी मोड** - किसी भी ट्रैक को लोफी वाइब में बदलें: धीमा 0.9×, पिच सुधार, देशी रीवरब।
- **इक्वलाइज़र और नेटिव इफेक्ट्स** - बैकग्राउंड प्लेबैक और स्क्रीन-ऑफ ऑडियो के साथ सिस्टम-स्तरीय ईक्यू।
- **बहु-भाषा ऑडियो और गुणवत्ता नियंत्रण** - उपलब्ध ऑडियो भाषाओं का पता लगाएं और उच्च/मध्यम/निम्न गुणवत्ता स्ट्रीम करें।

### 🤖 एआई डीजे और वैयक्तिकरण
- **एआई डीजे असिस्टेंट (Gemini)** - एक संवादी डीजे जो आपकी पसंद को पढ़ता है, स्मार्ट प्लेलिस्ट बनाता है और अनुरोध लेता है।
- **स्वाद संकेत** - प्रति-ट्रैक स्वाद स्कोरिंग से पता चलता है कि आपको क्या पसंद है और अनुशंसाएँ मिलती हैं।
- **Wrapped और सुनने के आँकड़े** — आपकी वर्ष-समीक्षा: शीर्ष कलाकार, मूड और सुनने के कैप्सूल।
- **स्मार्ट कैश सिस्टम** - ऑडियो की एसिंक पृष्ठभूमि कैशिंग + तत्काल, शून्य-प्रतीक्षा प्लेबैक के लिए बहु-रिज़ॉल्यूशन कलाकृति।

- **वैश्विक खोज** - गाने, वीडियो, एल्बम, कलाकार और पॉडकास्ट पर एक खोज।
- **चलाने के लिए साझा करें** — YouTube/YT संगीत लिंक सीधे Tunefy में साझा करें।

### 📻 रेडियो, संगीत कार्यक्रम और वीडियो
- **इंटरनेट रेडियो** - हजारों लाइव स्टेशन (Radio Browser)।
- **संगीत कार्यक्रम** - समृद्ध विवरण पृष्ठों के साथ अपने आस-पास की लाइव घटनाओं की खोज करें।
- **क्लिप फ़ीड** - समुदाय और ट्रेंडिंग क्लिप की लंबवत लघु-वीडियो फ़ीड।
- **वीडियो प्लेयर** - कैनवास वीडियो पृष्ठभूमि के साथ पूर्ण वीडियो प्लेबैक।
- **डीजे मिक्स** - समर्पित डीजे/मिक्स खोज और प्लेबैक।

### 🤝 सामाजिक, मिश्रण और समुदाय
- **Blend प्लेलिस्ट** — एक संक्षिप्त जॉइन कोड के साथ एक साझा प्लेलिस्ट बनाएं (जैसे `KORA-4821`); कोड वाला कोई भी व्यक्ति सुन सकता है और योगदान दे सकता है, जैसे Spotify Blend लिंक।
- **सामुदायिक फ़ीड** - समुदाय द्वारा अपलोड किए गए ट्रैक खोजें, स्ट्रीम करें और खोजें।
- **कलाकार अनुसरण** — कलाकारों/चैनलों पर नज़र रखने के लिए उनका अनुसरण करें।
- **स्मार्ट कतार और अनंत प्लेबैक** - बुद्धिमान स्पष्ट व्यवहार के साथ ऑटो-कतार।

### 🔐 गोपनीयता एवं खाते
- **किसी खाते की आवश्यकता नहीं** - पसंदीदा, प्लेलिस्ट और इतिहास डिफ़ॉल्ट रूप से स्थानीय रूप से संग्रहीत होते हैं।
- **गुमनाम + Google साइन-इन** - क्लाउड सिंक और प्रोफ़ाइल के लिए वैकल्पिक साइन-इन (गुमनाम डिवाइस पहचान या Supabase प्रामाणिक के माध्यम से Google)।
- **ऑफ़लाइन डाउनलोड** — ऑफ़लाइन सुनने के लिए गाने और वीडियो डाउनलोड करें।
- **डीप लिंकिंग** - ब्राउज़र या साझा लिंक के माध्यम से गाने, कलाकार, एल्बम और प्लेलिस्ट खोलने/प्ले करने के लिए पूर्ण कस्टम यूआरएल योजना।
- **विज्ञापन-मुक्त और विश्वसनीय** - प्लेबैक की गारंटी के लिए खुले रिले (Last.fm, MusicBrainz, iTunes) द्वारा समर्थित निर्बाध श्रवण।

## 🏗️वास्तुकला

```
tunefy-music/
├── lib/                     # Flutter app (Riverpod + Just Audio)
│   ├── l10n/                # 14-language localization
│   ├── providers/           # Riverpod state
│   ├── screens/             # UI screens
│   ├── services/            # Sources, streaming, AI DJ, sync
│   └── widgets/             # Reusable components
├── server/                  # ☁️ Cloud stream relay (Render)  ← see below
├── backend/                 # Local/stream API + yt-dlp helpers
├── supabase/migrations/     # Postgres schema + RLS policies
└── images/, assets/         # Screenshots & brand assets
```

**प्लेबैक विश्वसनीयता।** ऐप कभी भी किसी एक प्रदाता पर निर्भर नहीं होता है। यह ए में स्रोतों की जांच करता है
प्राथमिकता कैस्केड (स्थानीय रिले → क्लाउड रिले → बिना चाबी दर्पण → मेटाडेटा/शीर्षक खोज), एक के साथ
सर्किट ब्रेकर जो विफल हो रहे स्रोत को छोड़ देता है। **क्लाउड रिले** एक स्ट्रीम को हल करता है और फिर
**बाइट्स को रिले करता है** अपने स्वयं के कनेक्शन के माध्यम से ताकि रिज़ॉल्यूशन और प्लेबैक एक आईपी साझा करें - यह है
Googlevideo लिंक पर IP-लॉक 403 से क्या बचा जाता है।

   ```bash
   flutter pub get
   ```

3. **ऐप चलाएँ:**
   ```bash
   flutter run
   ```

4. **बिल्ड रिलीज़ एपीके** (छोटे आकार के लिए एबीआई द्वारा विभाजित):
   ```bash
   flutter build apk --split-per-abi
   ```

> क्लाउड रिले यूआरएल `lib/utils/api_constants.dart` में बेक किया गया है
> (`relayBaseUrl`), इसलिए किसी बिल्ड फ़्लैग की आवश्यकता नहीं है। अपने स्वयं के रिले को इंगित करने के लिए:
> `flutter run --dart-define=RELAY_BASE_URL=https://your-relay.onrender.com`.

## 🖥️ बैकएंड और स्ट्रीमिंग सर्वर

### ☁️ क्लाउड स्ट्रीम रिले - `server/` (Render पर तैनात)
YouTube ऑडियो यूआरएल को हल करता है **और बाइट्स को रिले करता है** ताकि फोन और रिज़ॉल्वर एक आईपी साझा करें
(संख्या 403). FastAPI + yt-dlp, Docker, फ्री टियर।

| समापन बिंदु | विवरण |
| --- | --- |
| `GET /health` | जीवंतता जांच (`ok`) |
| `GET /stream?videoId=X&key=K` | yt-dlp के माध्यम से हल होता है → एक `…/relay` यूआरएल लौटाता है (200 केवल अगर यह हल हो जाता है) |
| `GET /relay?videoId=X&key=K` | ऑडियो बाइट्स को प्रॉक्सी करता है (रेंज-अवेयर → खोजने के लिए 206) |

एक साझा `RELAY_KEY` env var द्वारा संरक्षित (इसके बिना **401** लौटता है)। परिनियोजन: Render →
**Root Directory = `server`**, Docker, **Health Check = `/health`**. देखें `server/README.md`.

### 🎵 ऐप एपीआई — `backend/`
डेटा/खोज बैकएंड (YouTube Music youtubei.js के माध्यम से + खुले स्रोत: Last.fm शैलियाँ,
MusicBrainz रिलीज़ और दशक)।

| समापन बिंदु | विवरण |
| --- | --- |
| `/api/search` | संगीत/वीडियो खोज |
| `/api/trending` | ट्रेंडिंग |
| `/api/charts` | YT संगीत चार्ट |
| `/api/playlist/:id` | प्लेलिस्ट विवरण |
| `/api/moods`, `/api/moods/:id` | श्रेणियाँ और मनोदशाएँ (Last.fm फ़ॉलबैक) |
| `/api/tags?tag=` | शैली के शीर्ष ट्रैक/एल्बम (Last.fm) |
| `/api/newreleases` | नई रिलीज़ (MusicBrainz) |
| `/api/decades?year=` | दशक के अनुसार एल्बम (MusicBrainz) |
| `/api/categories` | श्रेणी सूची |

**स्थानीय:** `cd backend && npm install && npm start` (पोर्ट 8000)।
**तैनाती (Vercel):** इस रेपो को आयात करें, **Root Directory = `backend`**। देखें `backend/README.md`.

### 🗄️ डेटाबेस — `supabase/`
Postgres **पंक्ति-स्तरीय सुरक्षा** के साथ स्कीमा: उपयोगकर्ता पंक्तियों का दायरा `auth.uid()` तक है, कैटलॉग है
अनाम उपयोगकर्ताओं के लिए केवल पढ़ने योग्य और केवल सेवा भूमिका द्वारा लिखने योग्य। Supabase में माइग्रेशन चलाएँ
SQL संपादक (क्रम में)।
